# بوابة المنتدى العامة — GitHub Pages

## الصلاحيات
- الزائر: قراءة الصفحة والبيانات العامة فقط، ولا توجد أزرار تحرير أو إرسال.
- صاحب المستودع: تعديل `public-data.json` و`index.html` من داخل GitHub؛ أي شخص تمنحه صلاحية Write يستطيع التعديل أيضًا. لذا لا تمنح الآخرين Write/Admin.
- لا تضع أسماء خاصة أو هواتف أو تقارير سرية أو رموز وصول في هذا المستودع؛ كل ما يُرفع إلى مستودع عام يمكن الاطلاع عليه.

## النشر
1. افتح github.com وسجّل الدخول بالحساب الذي تريد أن يكون المالك.
2. أنشئ مستودعًا عامًا جديدًا باسم `volunteer-forum-dashboard` (Public).
3. ارفع `index.html` و`public-data.json` إلى جذر المستودع ثم نفّذ Commit.
4. من Settings → Pages اختر Deploy from a branch، الفرع `main` والمجلد `/(root)` ثم Save.
5. سيكون العنوان عادةً: `https://USERNAME.github.io/volunteer-forum-dashboard/` بعد الاستقرار.

## التعديل
عدّل `public-data.json` ثم Commit. الموقع للقراءة فقط، وليس به تسجيل دخول أو تعديل من داخله.

## الربط المستقبلي
هذه النسخة **غير متصلة** مباشرة بالملف المركزي، حفاظًا على خصوصيته. إذا رُبطت لاحقًا بـ Google Sheets فيجب استخدام جدول نشر عام منفصل يتضمن حقولًا مسموح نشرها فقط، لا جعل الملف المركزي عامًا.
